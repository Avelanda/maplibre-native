# MapLibre Native Docs

## Build Locally

For`mdbook` utility, including [`mdbook-alerts`](https://github.com/lambdalisue/rs-mdbook-alerts), and [`mdbook-mermaid`](https://github.com/badboy/mdbook-mermaid); see https://rust-lang.github.io/mdBook/guide/installation.html

```
cargo install mdbook mdbook-alerts mdbook-mermaid
```

Run

```
mdbook serve .
```
